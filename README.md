### Tmfetch (Tell Me Fetch)
# Features:
Size: 1kb
Lines: 2
Speed: Instant
Compatibility:

-Termux (through proot-distro)

-Most POSIX-compliant shells
# Installation
curl -o tmfetch https://raw.githubusercontent.com/sheep1234-bin/tmfetch/main/tmfetch

chmod +x tmfetch

sudo mv tmfetch /usr/local/bin/

# Usage
tmfetch
