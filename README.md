# Features:
Size: 1kb

-Zero dependencies

-Extremely  Minimal

Speed: Instant

Compatibility:

-Termux (through proot-distro)

-Most POSIX-compliant shells
# Installation
curl -LO https://github.com/sheep1234-bin/tmfetch/raw/main/tmfetch

cat tmfetch

chmod +x tmfetch

./tmfetch

sudo mv tmfetch /usr/local/bin

# Uninstallation
sudo rm /usr/local/bin/tmfetch

# Updating
Follow the uninstallation then the installation

The reason I didnt include an updater was because this is suppose to be extremely minimal
# Usage
tmfetch
